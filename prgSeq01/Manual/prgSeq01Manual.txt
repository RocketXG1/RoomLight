FINALIDAD DEL CODIGO
====================
El archivo prgSeq01.py implementa una secuencia de control para una luz negra y
un indicador NeoPixel en una placa compatible con MicroPython.

La finalidad principal del codigo es:
1. Leer un switch digital conectado al GPIO 27.
2. Controlar una luz negra por PWM usando el pin 28 y la clase
   BlackLightControl.
3. Mantener un estado interno de la luz: apagada o encendida.
4. Ejecutar una rampa cuando el switch permanece en alto durante un tiempo
   definido.
5. Mostrar el estado del sistema en un NeoPixel conectado al GPIO 16.

Funcionamiento general:
- Al iniciar, la luz negra se coloca en LIGHT_OFF_PERCENT = 100.
- En este hardware el porcentaje esta invertido: 100 % representa la luz
  apagada y 50 % representa la luz encendida.
- El NeoPixel se configura con brillo bajo y color cian para indicar que el
  sistema esta listo.
- Si la luz esta apagada, el programa espera que el switch permanezca en alto
  durante WAKE_HOLD_SECONDS = 0.5 segundos. Cuando se cumple ese tiempo, llama
  a fbiWakeUp(), cambia el NeoPixel a verde y marca el estado interno como
  encendido.
- Si la luz esta encendida, el programa espera que el switch permanezca en alto
  durante SLEEP_HOLD_SECONDS = 2 segundos. Cuando se cumple ese tiempo, llama a
  fbiSleep(), cambia el NeoPixel a rojo y marca el estado interno como apagado.
- Despues de cada cambio, wait_for_low() obliga a que el switch vuelva a bajo
  antes de aceptar una nueva activacion. Esto evita cambios repetidos si el
  switch se queda presionado o si la senal permanece en alto.


CLASES, MODULOS IMPORTADOS E INSTANCIAS
=======================================

Linea 8: import time
--------------------
Importa el modulo time de MicroPython. Este modulo no se instancia; se usa
directamente llamando a sus funciones.

En prgSeq01.py se utiliza para:
- time.ticks_ms(): leer el contador interno de milisegundos.
- time.ticks_diff(actual, inicial): calcular diferencias entre ticks de forma
  segura ante overflow.
- time.sleep(segundos): pausar la ejecucion entre lecturas del switch.

Linea 9: from machine import Pin
--------------------------------
Importa la clase Pin del modulo machine. Pin permite configurar y manipular
pines GPIO del microcontrolador.

Metodo usado en este codigo:
- value(): lee el estado logico del pin. Devuelve 0 cuando esta en bajo y un
  valor verdadero cuando esta en alto.

Instancia creada:
- Linea 38: bSensor = Pin(SWITCH_PIN, Pin.IN)
  Crea un objeto Pin llamado bSensor usando SWITCH_PIN, que vale 27. El segundo
  argumento, Pin.IN, configura el GPIO 27 como entrada digital. Esta instancia
  se usa en wait_for_high_hold() y wait_for_low() para saber si el switch esta
  alto o bajo.

Linea 10: from lib.Neopixel.neopixel import Neopixel
----------------------------------------------------
Importa la clase Neopixel desde la libreria local lib/Neopixel/neopixel.py. La
clase Neopixel controla LEDs direccionables mediante PIO/state machine.

Metodos de Neopixel usados en este codigo:
- brightness(valor): ajusta el brillo global que se aplica al actualizar los
  LEDs. En este codigo se llama como Ready.brightness(10), por lo que el LED se
  muestra con brillo bajo.
- fill(color): escribe el mismo color en todos los LEDs del objeto. Como Ready
  se instancia con un solo LED, fill() cambia el color de ese unico indicador.
- show(): envia al hardware el contenido guardado en el buffer interno de
  pixeles. Si se llama fill() pero no se llama show(), el color puede quedar en
  memoria sin verse fisicamente en el LED.

Instancia creada:
- Linea 40: Ready = Neopixel(1, 1, 16, "GRB")
  Crea un indicador NeoPixel llamado Ready.
  Parametros usados:
  - 1: numero de LEDs.
  - 1: numero de state machine PIO usado por la libreria.
  - 16: GPIO donde esta conectado el NeoPixel.
  - "GRB": orden de color del LED. Muchos NeoPixel esperan los canales en
    orden verde-rojo-azul en lugar de rojo-verde-azul.

Linea 11: from lib.BlackLight.BlackLightControl import BlackLightControl
------------------------------------------------------------------------
Importa la clase BlackLightControl desde la libreria local
lib/BlackLight/BlackLightControl.py. Esta clase encapsula el control PWM de la
luz negra.

Metodos de BlackLightControl usados en este codigo:
- set_percent(percent): limita el porcentaje entre 0 y 100, lo convierte a duty
  de 16 bits y lo aplica al PWM con duty_u16(). En este proyecto el hardware
  esta invertido, por lo que set_percent(100) apaga la luz y set_percent(50) la
  deja encendida al nivel requerido.
- ramp_percent(step_percent, total_time_s, start_percent, end_percent): genera
  una transicion gradual desde start_percent hasta end_percent. Internamente
  calcula la direccion, el numero de pasos y el retardo entre pasos, llamando a
  set_percent() en cada avance.
- deinit(): libera el recurso PWM asociado al pin cuando el programa termina o
  se interrumpe.

Instancia creada:
- Linea 39: BlackLight = BlackLightControl(BLACK_LIGHT_PIN,
  BLACK_LIGHT_FREQUENCY)
  Crea el controlador de la luz negra en el GPIO 28 con frecuencia PWM de
  1000 Hz. Esta instancia se usa para set_percent(), ramp_percent() y deinit().

Funcion wait_for_high_hold(hold_seconds) - lineas 73 a 86
---------------------------------------------------------
Objetivo:
- Esperar hasta que el switch permanezca en alto de forma continua durante el
  tiempo indicado.

Parametro:
- hold_seconds: cantidad de segundos que la senal debe mantenerse en alto.

Explicacion de la logica:
- high_started_at = None: indica que todavia no se ha detectado el inicio de
  una senal alta continua.
- while True: crea un ciclo de espera que solo termina con return.
- if bSensor.value(): lee el GPIO 27. Si el switch esta en alto, entra al bloque
  de conteo.
- if high_started_at is None: si es el primer ciclo en alto, guarda el momento
  actual con _ticks_ms().
- elif _elapsed_seconds(high_started_at) >= hold_seconds: si la senal lleva en
  alto al menos el tiempo requerido, termina la funcion con return.
- else: si bSensor.value() es falso, significa que la senal esta en bajo.
- high_started_at = None: reinicia la cuenta cuando la senal baja. Esto obliga a
  que el siguiente intento permanezca en alto desde cero, sin acumular tiempos
  de pulsos separados.
- time.sleep(POLL_DELAY_SECONDS): espera 0.05 segundos antes de volver a leer.

Funcion wait_for_low() - lineas 89 a 92
---------------------------------------

Explicacion:
- while bSensor.value(): mientras el GPIO 27 siga en alto, el programa no sale

- time.sleep(POLL_DELAY_SECONDS): espera 0.05 segundos entre lecturas.

Importancia:
- Evita que una misma presion larga o una senal mantenida en alto active dos
  cambios de estado consecutivos.

USO DE ticks_ms, COMO FUNCIONA Y COMO SE "INSTANCIA"
====================================================

time.ticks_ms()
---------------
time.ticks_ms() es una funcion del modulo time de MicroPython. No es una clase
y no se instancia con parentesis de constructor como Pin(...) o Neopixel(...).
Su uso correcto es llamarla directamente:

    tick_actual = time.ticks_ms()

Que devuelve:
- Un numero entero que representa el contador interno de milisegundos del
  sistema.
- Ese numero sirve para medir intervalos de tiempo, no para obtener una hora de
  calendario.

Por que no se debe restar directamente:
- El contador de ticks puede desbordarse despues de cierto tiempo y volver a un
  rango inicial.
- Si se hace una resta normal, por ejemplo actual - inicial, el resultado puede
  ser incorrecto cuando ocurre overflow.

Forma segura de medir tiempo:

    inicial = time.ticks_ms()
    transcurrido_ms = time.ticks_diff(time.ticks_ms(), inicial)

En este codigo:
- _ticks_ms() envuelve time.ticks_ms() para obtener el tick inicial.
- _elapsed_seconds(start_ticks) usa time.ticks_diff() para calcular la
  diferencia de forma segura.
- wait_for_high_hold() combina ambas funciones para validar que el switch haya
  permanecido en alto durante el tiempo requerido.

Como "instanciarlo" en el contexto del codigo:
- ticks_ms no se instancia porque no es objeto ni clase.
- Lo que si se hace es guardar una lectura del contador en una variable:

    high_started_at = _ticks_ms()

- high_started_at queda como una referencia temporal del inicio de la senal en
  alto.
- Despues, el codigo compara el tiempo actual contra esa referencia:

    _elapsed_seconds(high_started_at) >= hold_seconds

Este patron equivale a crear un punto de inicio para un temporizador sin usar
una clase Timer.

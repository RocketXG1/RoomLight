FINALIDAD DEL CODIGO
====================
El archivo prgSeq01.py tiene como finalidad controlar una luz negra por PWM
usando la clase BlackLightControl y un switch conectado al GPIO 27.

La secuencia inicia apagando la luz con set_percent(100), porque en este
hardware el porcentaje esta invertido: 100 % representa luz apagada y 50 %
representa luz encendida. Despues de iniciar, el programa queda escuchando el
GPIO 27. Si la entrada permanece en alto durante 2 segundos cuando la luz esta
apagada, se ejecuta fbiWakeUp() una sola vez y el estado interno cambia a On.
Si la entrada permanece en alto durante 3 segundos o mas cuando la luz esta
encendida, se ejecuta fbiSleep() una sola vez y el estado interno cambia a Off.


CLASES, MODULOS IMPORTADOS E INSTANCIAS
=======================================
Linea 8: import time
--------------------
Importa el modulo time de MicroPython. Este modulo se usa para medir tiempo y
para pausar la ejecucion del programa. En este codigo se utiliza con:
- time.ticks_ms(): obtiene un contador interno en milisegundos.
- time.ticks_diff(actual, inicial): calcula la diferencia entre dos contadores
  de ticks de forma segura aunque el contador interno tenga overflow.
- time.sleep(segundos): espera una cantidad de segundos antes de continuar.

Linea 9: from machine import Pin
--------------------------------
Importa la clase Pin del modulo machine. Pin permite configurar y leer pines
GPIO del microcontrolador. En este codigo se usa para crear la entrada del
switch conectado al GPIO 27.

Instancia de Pin en la linea 27:
    bSensor = Pin(SWITCH_PIN, Pin.IN)

Esta instancia crea el objeto bSensor. SWITCH_PIN vale 27, por lo tanto bSensor
lee el GPIO 27. Pin.IN configura el pin como entrada digital. El metodo usado
de esta instancia es:
- bSensor.value(): lee el estado del pin. Si regresa 1 o True, la entrada esta
  en alto; si regresa 0 o False, la entrada esta en bajo.

Linea 10: from lib.BlackLight.BlackLightControl import BlackLightControl
------------------------------------------------------------------------
Importa la clase BlackLightControl desde el archivo lib/BlackLight/
BlackLightControl.py. Esta clase encapsula el control PWM de la luz negra.

Metodos importantes de BlackLightControl usados en este codigo:
- __init__(pin, frequency=1000): inicializa el PWM en el pin indicado y define
  la frecuencia. En este programa se instancia con pin 28 y frecuencia 1000 Hz.
- set_percent(percent): fija directamente el porcentaje PWM. El codigo lo usa
  al inicio con set_percent(100) para apagar la luz.
- ramp_percent(step_percent, total_time_s, start_percent, end_percent): realiza
  una rampa desde start_percent hasta end_percent usando pasos de porcentaje y
  distribuyendo el movimiento durante total_time_s segundos.
- deinit(): libera el PWM al salir del programa.

Instancia de BlackLightControl en la linea 28:
    BlackLight = BlackLightControl(BLACK_LIGHT_PIN, BLACK_LIGHT_FREQUENCY)

BLACK_LIGHT_PIN vale 28 y BLACK_LIGHT_FREQUENCY vale 1000. Por lo tanto, esta
instancia controla la luz negra en el pin 28 con una frecuencia PWM de 1000 Hz.

EXPLICACION DE FUNCIONES
========================
Funcion _ticks_ms() - lineas 31 a 33
------------------------------------
Esta funcion regresa time.ticks_ms(). Su objetivo es centralizar la lectura del
contador de milisegundos de MicroPython.

Uso de ticks_ms:
- time.ticks_ms() no se instancia como una clase; se llama como funcion del
  modulo time.
- Regresa un numero que representa milisegundos transcurridos en un contador
  interno del microcontrolador.
- Ese contador puede reiniciarse por overflow despues de cierto tiempo. Por eso
  no es recomendable restar ticks manualmente.
- En este codigo, _ticks_ms() se llama cuando el GPIO 27 pasa a alto para
  guardar el momento inicial en la variable high_started_at.

Funcion _elapsed_seconds(start_ticks) - lineas 36 a 38
------------------------------------------------------
Calcula cuantos segundos han pasado desde start_ticks. Internamente usa:
    time.ticks_diff(time.ticks_ms(), start_ticks) / 1000

Como funciona:
- time.ticks_ms() obtiene el tick actual.
- time.ticks_diff(actual, start_ticks) calcula la diferencia en milisegundos.
- La division entre 1000 convierte milisegundos a segundos.
- ticks_diff se usa porque maneja correctamente el overflow del contador de
  ticks, algo que una resta directa podria calcular mal.

Funcion fbiWakeUp() - lineas 41 a 48
------------------------------------
Esta funcion ejecuta la rampa para cambiar al estado On. Llama al metodo
BlackLight.ramp_percent con los parametros requeridos:
- step_percent = 1
- total_time_s = 0.5
- start_percent = 50
- end_percent = 100

Debido a que el hardware esta invertido, estos valores son los solicitados para
la accion de WakeUp. La funcion no contiene ciclos adicionales, por lo que cada
vez que se llama ejecuta una sola rampa.

Funcion fbiSleep() - lineas 51 a 58
-----------------------------------
Esta funcion ejecuta la rampa para cambiar al estado Off. Llama al metodo
BlackLight.ramp_percent con los parametros requeridos:
- step_percent = 1
- total_time_s = 0.5
- start_percent = 100
- end_percent = 50

La funcion se llama una sola vez cuando el switch permanece en alto durante 3
segundos o mas y el estado interno indica que la luz esta On.

Funcion wait_for_high_hold(hold_seconds) - lineas 61 a 74
---------------------------------------------------------
Esta funcion deja el programa a la escucha del GPIO 27 hasta que el switch
permanezca en alto durante el tiempo indicado por hold_seconds.

Explicacion linea a linea de la logica:
- high_started_at = None: indica que todavia no se ha detectado el inicio de
  una presion en alto.
- while True: mantiene la escucha de forma indefinida hasta cumplir el tiempo.
- if bSensor.value(): si el GPIO 27 esta en alto, se empieza o continua el
  conteo.
- if high_started_at is None: si es el primer momento detectado en alto, se
  guarda el tick actual con _ticks_ms().
- elif _elapsed_seconds(high_started_at) >= hold_seconds: si el tiempo en alto
  ya alcanzo el objetivo, la funcion termina con return.
- else: si el GPIO 27 esta en bajo, se reinicia high_started_at en None para
  obligar a que la siguiente activacion tenga que permanecer en alto desde cero.
- time.sleep(POLL_DELAY_SECONDS): pausa de 50 ms antes de volver a leer la
  entrada.

Funcion main() - lineas 77 a 90
-------------------------------
Es la funcion principal de la secuencia.

Explicacion de funcionamiento:
- light_is_on = False: define que el estado inicial interno de la luz es Off.
- BlackLight.set_percent(LIGHT_OFF_PERCENT): apaga fisicamente la luz al inicio
  usando set_percent(100).
- while True: mantiene la secuencia activa para escuchar el switch siempre.
- if light_is_on: si el estado interno esta On, espera una presion alta de 3
  segundos, llama fbiSleep() y cambia light_is_on a False.
- else: si el estado interno esta Off, espera una presion alta de 2 segundos,
  llama fbiWakeUp() y cambia light_is_on a True.

Bloque de ejecucion principal - lineas 93 a 97
----------------------------------------------
El bloque:
    if __name__ == "__main__":

permite que main() se ejecute solamente cuando prgSeq01.py se ejecuta como
programa principal. Dentro se usa:
- try: llama a main().
- finally: llama a BlackLight.deinit() si el programa termina o se interrumpe.

Esto ayuda a liberar el recurso PWM de la luz negra.

USO DEL CODIGO
==============
1. Colocar prgSeq01.py dentro de la carpeta prgSeq01 del proyecto.
2. Verificar que el switch este conectado al GPIO 27.
3. Verificar que la luz negra este conectada al pin PWM 28.
4. Ejecutar prgSeq01.py en el microcontrolador compatible con MicroPython.
5. Al iniciar, la luz se apaga con set_percent(100) y el estado queda Off.
6. Mantener el switch en alto durante 2 segundos para llamar fbiWakeUp() una
   sola vez y pasar el estado a On.
7. Con la luz en estado On, mantener el switch en alto durante 3 segundos o mas
   para llamar fbiSleep() una sola vez y regresar el estado a Off.
8. La secuencia vuelve siempre a la escucha despues de terminar cada rampa.


NOTAS IMPORTANTES
=================
- El programa esta pensado para MicroPython porque usa machine.Pin,
  time.ticks_ms() y time.ticks_diff().
- El hardware esta invertido: 100 % se documenta como apagado y 50 % como
  encendido.
- Si el switch baja antes de cumplir 2 o 3 segundos, el conteo se reinicia.
- fbiWakeUp() y fbiSleep() no se repiten continuamente; se ejecutan una sola vez
  cuando wait_for_high_hold() confirma el tiempo requerido.
